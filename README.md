## 🚀 วิธีการเปิดใช้งานระบบ

ระบบถูกออกแบบให้ทำงานได้ **2 รูปแบบ** เพื่อความยืดหยุ่นสูงสุดในโรงพยาบาล:

### แบบที่ 1: เปิดใช้งานได้ทันทีบนเว็บเบราว์เซอร์ (Standalone Mode - แนะนำสำหรับใช้งานทันที)
1. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้ เช่น Google Chrome, Microsoft Edge, Firefox
2. ระบบจะโหลดหน้าจอ **แดชบอร์ด** และฐานข้อมูลยาโรงพยาบาลพร้อมข้อมูลตัวอย่างขึ้นมาให้ใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

### แบบที่ 2: รันเป็นเว็บเซิร์ฟเวอร์ภายในเครือข่ายโรงพยาบาล (Node.js LAN Server)
1. เปิด Terminal ในโฟลเดอร์นี้
2. ติดตั้งโมดูล:
   ```bash
   npm install
   ```
3. เริ่มต้นการทำงานของเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
4. เข้าใช้งานผ่านเบราว์เซอร์ที่: `http://localhost:3000` (หรือ IP เครื่องเซิร์ฟเวอร์ในเครือข่ายโรงพยาบาล)

## 🌟 ฟังก์ชันหลักของระบบ

### 1. แดชบอร์ด (Dashboard)
* **KPI Cards:** แสดงมูลค่ายาคืนรวม (บาท), จำนวนหน่วยยาที่รับคืน, จำนวนชนิดยา, และจำนวนครั้งที่บันทึก
* **ตัวกรอง (Filter Bar):** ปรับช่วงวันที่ (เริ่มต้น-สิ้นสุด) และแหล่งที่มา (ทั้งหมด, OPD, IPD, กล่องยาคืนทั่วไป) พร้อมปุ่มเลือกช่วงเวลาด่วน (วันนี้, 7 วันล่าสุด, เดือนนี้, ปีนี้, ทั้งหมด)
* **กราฟ 10 อันดับยาที่มีมูลค่าการรับคืนสูงสุด (Top 10):** Horizontal Bar Chart แสดงชื่อยา จำนวน และมูลค่า พร้อมตารางสรุป
* **กราฟแนวโน้มรายเดือน (Monthly Trend):** Bar/Line Chart แสดงมูลค่าและจำนวนหน่วยยารับคืนตลอด 12 เดือนของปี พ.ศ.
* **กราฟสัดส่วนตามแหล่งที่มา (Source Breakdown):** เปรียบเทียบ OPD vs IPD vs กล่องยาคืนทั่วไป

### 2. บันทึกการรับยาคืน (Return Form)
* วันที่รับข้อมูล (Date Picker) รองรับการแสดงผลวันที่แบบไทย (วัน/เดือน/ปี พ.ศ. เช่น 05/09/2569) และรองรับการบันทึกย้อนหลัง
* เลือกแหล่งที่มา 3 ตัวเลือก: `OPD`, `IPD`, `กล่องยาคืนทั่วไป`
* **ระบบพิมพ์ค้นหายาแบบ Autocomplete Typeahead (ใหม่):** สามารถพิมพ์ค้นหาด้วย **ชื่อยา, รหัสยา หรือ Generic name** ได้โดยตรง พร้อมแสดงผลการค้นหาทันทีแบบ Real-time
* **แถบค้นหาและเพิ่มยาแบบด่วน (Quick Search Bar):** พิมพ์ค้นหาเหนือตารางแล้วกดเลือก ยาจะถูกเพิ่มลงตารางพร้อมเลื่อนเคอร์เซอร์ไปที่ช่อง "จำนวน" ทันที เพื่อความรวดเร็วสูงสุด
* ตารางเพิ่มรายการยาได้หลายรายการใน 1 ครั้ง
* เมื่อเลือกยา ระบบจะดึงข้อมูล **รหัสยา, ชื่อยา, Generic Name, Dosage Form และต้นทุนต่อหน่วย** อัตโนมัติ พร้อมแสดง Badge ป้องกันการเลือกยาผิด
* ผู้ใช้กรอกเฉพาะ **จำนวนยา**
* **ระบบคำนวณมูลค่ารวมอัตโนมัติแบบ Real-time:** `มูลค่ารวม = จำนวน × ต้นทุนต่อหน่วย` (ผู้ใช้ไม่สามารถแก้ไขต้นทุนได้)
* แสดง **มูลค่ารวมทั้งหมด (Grand Total)** อัปเดตทันที
* ยืนยันบันทึกข้อมูลแบบ **Database Transaction** (ปลอดภัย ข้อมูลครบถ้วน)

### 3. รายงานข้อมูลยาคืน (Reports)
* ดูรายงานได้ 4 รูปแบบ:
  * **รายวัน:** เลือกวันที่ แสดงตารางรายการยาและยอดรวมประจำวัน
  * **รายสัปดาห์:** สรุปยอดรวมประจำสัปดาห์
  * **รายเดือน:** เลือกเดือนและปี พ.ศ. แสดงรายการยาและยอดรวมประจำเดือน
  * **รายปี:** เลือกปี พ.ศ. แสดงตารางสรุปเปรียบเทียบ 12 เดือน พร้อมยอดรวมประจำปี และปุ่มเจาะดูข้อมูลรายเดือน (Drill-down)
* ระบบค้นหาตามชื่อยา, รหัสยา, Generic Name หรือแหล่งที่มา
* เรียงลำดับข้อมูลตาม วันที่, จำนวน หรือมูลค่า
* ปุ่มดูรายละเอียดบิลย้อนหลัง (Receipt Modal)
* ปุ่ม Export Excel หน้ารายงานได้ทันที

### 4. จัดการรายการยา (Medicine Catalog)
* แสดงรายการยาทั้งหมดในโรงพยาบาล พร้อมสถานะ **เปิดใช้งาน (Active)** หรือ **ปิดใช้งาน (Inactive)**
* ปุ่ม `+ เพิ่มรายการยาใหม่` พร้อมระบบตรวจสอบรหัสยาไม่ซ้ำ
* ปุ่มแก้ไขข้อมูลยา (ชื่อยา, generic name, dosage form, ต้นทุน)
* ปุ่มสลับสถานะเปิด/ปิดใช้งาน (Soft Status) ป้องกันการลบข้อมูลถาวร เพื่อให้ประวัติยาคืนในอดีตคงอยู่สมบูรณ์

### 5. นำเข้ารายการยา (Import Excel / CSV)
* อัปโหลดไฟล์ `.xlsx` หรือ `.csv`
* **ยึดรหัสยาและชื่อยาตามไฟล์ที่นำเข้าทั้งหมด 100% ห้ามเปลี่ยนรหัสเด็ดขาด:** ระบบจะไม่สร้างรหัสยาจำลอง และคงรหัสยาตามไฟล์ไว้ทุกตัวอักษร
* มีโหมดการนำเข้า 2 รูปแบบให้เลือก:
  1. **อัปเดตและเพิ่มใหม่ตามไฟล์ (Upsert) - รักษารหัสเดิม 100%:** ถ้ารหัสยาตรงกับที่มีในระบบ ให้อัปเดตชื่อยาและราคาตามไฟล์ใหม่ หากเป็นรหัสใหม่ให้เพิ่มเข้าไป โดยคงรหัสยาตามไฟล์ไว้เสมอ
  2. **แทนที่ฐานข้อมูลยาทั้งหมดด้วยไฟล์นี้ (Replace Catalog):** ล้างรายการยาเดิมและใช้รายการยาตามไฟล์ทั้งหมดตรงตามรหัสและชื่อในไฟล์
* ระบบตรวจจับคอลัมน์อัตโนมัติ: รหัสยา, ชื่อยา, Generic name, Dosage form, ต้นทุนต่อหน่วย
* ตาราง **Preview ข้อมูลก่อนบันทึก** พร้อมตรวจสอบ:
  * แถวที่รหัสยาใหม่พร้อมเพิ่มเข้าระบบ (สีเขียว)
  * แถวที่มีรหัสยาเดิมในระบบและจะอัปเดตชื่อ/ราคาตามไฟล์ (สีฟ้า)
  * แถวที่ข้อมูลไม่สมบูรณ์ เช่น ไม่มีรหัสยาหรือไม่มีชื่อยา (สีแดง)
* ปุ่ม **“ยืนยันนำเข้าข้อมูล”** และ **“ยกเลิก”**
* ปุ่มดาวน์โหลดไฟล์เทมเพลต Excel สำหรับบุคลากร

### 6. ส่งออกข้อมูล (Export Excel)
* ส่งออกไฟล์ `.xlsx` ตามช่วงวันที่และแหล่งที่มาที่ผู้ใช้เลือก
* หัวตารางมาตรฐาน: ลำดับ, วันที่รับคืน (พ.ศ.), แหล่งที่มา, รหัสยา, รายการยา, Generic name, Dosage form, จำนวน, ต้นทุนต่อหน่วย (บาท), มูลค่ารวม (บาท)
* แถวสรุปรวมท้ายตาราง (รวมจำนวน และ รวมมูลค่า)

### 7. ตรวจสอบระบบตาม 12 Test Cases (Test Cases Runner)
* เมนูพิเศษในระบบสำหรับผู้บริหารหรือผู้ตรวจสอบ สามารถกดปุ่ม **“เริ่มรันการทดสอบทั้งหมด (Run All)”** เพื่อให้ระบบทดสอบและแสดงผลผ่าน (PASSED) ครบทั้ง 12 เกณฑ์
